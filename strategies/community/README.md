# Community strategies

Open a pull request that adds ONE file here: `strategies/community/<yourname>_<idea>.py`.
It must follow the contract in `PROMPT.md` (define `strategy(df)`), run cleanly with
`python backtest.py strategies\community\<file>.py`, and start with a docstring saying what the idea is
and the SUBMIT line you got. `python backtest.py --all` runs this folder too.
